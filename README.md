# HR Analytics Dashboard

An Excel dashboard for headcount, attrition and joiners, built on randomly generated sample data.

## What's inside
`HR-Analytics-Dashboard.xlsx`
- **Dashboard**: active headcount, exits and attrition rate, a department breakdown and a monthly joiners chart.
- **Data**: 140 sample employees (not real). Replace with your own data to reuse it.

## How it's calculated
Attrition rate = exits / (active + exits). Everything is a live formula, so the dashboard updates when the data changes.
